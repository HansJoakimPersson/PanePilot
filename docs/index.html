What PanePilot does

PanePilot gives you stable, repeatable snap zones without taking over the entire desktop. You keep normal window movement until you hold the configured modifier, then the app reveals available regions for the current display and snaps on drop.

  • Runs from the macOS menu bar
  • Per-display layout assignment
  • Built-in two-column, widescreen, and multi-column layouts
  • Top-half and bottom-half snaps inside a matching region
  • Start at Login support for signed app bundles
  • Debug logging for permission and window-move failures

How it works

  1. Download the latest release and move PanePilot.app to Applications.
  2. Launch the app and grant Accessibility access in System Settings.
  3. Open Settings to choose the snap modifier and review display layouts.
  4. Hold the modifier while dragging a window.
  5. Hover a region and release to snap.

PanePilot uses macOS Accessibility APIs to inspect and move windows. Some apps enforce minimum window sizes, so final geometry may be adjusted after the initial snap.
